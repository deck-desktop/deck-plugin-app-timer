# Changelog

## 1.2.0 (2026-10-30)

- A licence, this changelog, a README rewritten with a screenshot, and the permissions it uses
  declared. Built from its own lockfile.
- Fired timers are kept in this plugin's own data rather than a history shared with Power Timer, so
  the plugin no longer asks to change Deck itself. Deck moves the existing ones across once.
- The warning before a timer fires is set in Deck's Settings > General > Timers, beside the
  sound, rather than on this plugin's settings page. It needs a Deck that has it there.
- A timer set for a time of day can repeat on chosen days of the week, from the tab as well as
  from an agent.

## 1.1.0 (2026-10-18)

- The first version in Deck's plugin registry.
